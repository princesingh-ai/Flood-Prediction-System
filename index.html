About This Project

The AI-Based Flood Prediction System uses machine learning to estimate a numerical output from environmental and infrastructure-related features supplied by the user.

Technologies Used

Python Scikit-learn Random Forest FastAPI JavaScript Leaflet Maps OpenStreetMap

Current Limitations

The map locates places, but the current model does not automatically retrieve environmental data for those coordinates. Predictions depend on the feature values entered by the user. The model output is not a validated real-world flood probability.
